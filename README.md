# Practical 01 – Design a transistor biasing circuit and analyze the same.

## Aim
Design a transistor biasing circuit. I designed a Collector-Base Biasing Circuit

## Components Required
- Breadboard
- Connecting wires
- LED
- Resistors
- DC power supply

## Procedure
The required components were connected on the breadboard according to
the circuit diagram. Appropriate power supply connections were provided
and the output was observed using LEDs.

## Result
The aim was successfully verified using physical
breadboard connections.
